# Original archived images

Original image binaries were not accessible through the available archive retrieval interfaces. No replacement or invented images are included.

To activate each slot, place recovered images in this directory with these exact filenames:

- home-background.jpg — homepage background
- event-background.jpg — event-services background
- partner-background.jpg — community partner background
- video-transfers.jpg — video transfers service image
- image-scanning.jpg — image scanning service image
- film-conversion.jpg — film transfer service image
- audio-transfers.jpg — audio transfers service image

You can recover originals from the Wayback Machine's archived image URLs (look for wp-content/uploads or image URLs in the saved page source), your original WordPress media library, or your original website backup. Do not rename unrelated stock images as originals.

If an image is absent, its slot uses a neutral background and the page still works.
